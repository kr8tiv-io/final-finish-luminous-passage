# MOTION BIBLE — Final Finish Epoxy

Research date: 2026-09-18. Stack assumed: Astro 7 + React islands, GSAP 3.15 (all plugins, all free since 3.13), Three.js/R3F + drei, **native scroll**, `#FAF9F6` / `#164F83`, Manrope, poured-epoxy films, 96 real before/after photos.
Everything below was either verified live in a browser (ScrollTrigger counts, canvas counts, script lists, scroll mode) or cited to a URL. Previously decoded sites (jh3y cylinder, Creative Ocean self-mask, isladjan lags, Igloo render targets, Resn CGI, Young Multi, gsap.com folds, Lusion multi-canvas) are extended, not repeated.

## What "immersive" concretely means

- **Density of reveals, not length of hijack.** ERA Residence (Awwwards SOTM Aug 2026) runs **156 ScrollTrigger instances with 0 pins and 0 snaps** and 1,722 SplitText nodes. (Two independent probes agreed on 0 pins / 0 snap; scrub counts differed by page state, because the scrubbed media-parallax triggers are created lazily per section.) The feeling of movement comes from ~150 small, well-eased entrances — not from trapping the wheel.
- **One persistent stage the page scrolls past.** Montfort (Immersive Garden, SOTM Jun 2025) is **Astro** (`WebGL.astro`, `ChaptersNavigation.astro`, `ClientRouter.astro`) with a single fixed `#canvas-wrapper` behind 5 named chapter sections and 18 fixed elements. The canvas never unmounts; chapters scroll over it.
- **Sticky beats pin.** Son Daven (SOTM Jun 2026) uses **14 CSS `position:sticky` elements and 0 GSAP pins**. Sticky stacking gives layered depth with no pin-spacer, no refresh cost, no scroll-position math.
- **Axis change as punctuation, not as the spine.** Use horizontal once or twice (a bay of floors, a chapter of the pour) and return to vertical. Both NN/g and the Awwwards score sheet punish sustained axis capture.
- **Material behaviour is the subject.** The floor is the hero: matte → gloss, flake catching light, a reflection resolving. That is one plane whose *uniforms* lerp across chapters — not a model.
- **It must survive a phone.** Awwwards scores **Usability 30%** (Design 40, Creativity 20, Content 10) ([evaluation system](https://www.awwwards.com/about-evaluation/)). A jury member opens it on an iPhone. Every mechanic below has a phone plan.

**The uncomfortable finding:** of eight award winners probed, **five ship no Three.js at all**, and the two 2026 architecture/property winners are Webflow + GSAP + Lenis + CSS sticky. WebGL is not what is winning — *reveal density, material photography, and type choreography* are. Build the GSAP layer first; WebGL is the second act.

**The stack precedent you should copy:** Montfort and Oryzo AI are both **Astro**, both keep **one fixed persistent canvas** plus (Oryzo) inline per-tile canvases, and **Oryzo uses native scroll with no smooth-scroll library** — exactly the constraint set here.

**Settle the smooth-scroll question now.** Only 6 of 60 [GSAP Gallery](https://gsap.com/showcase/) sites are tagged ScrollSmoother; every smoothed winner probed here uses **Lenis**, which keeps the real `window.scrollY`, scrollbar and anchors and merely eases the value (no transform wrapper, no `scrollerProxy`). ScrollSmoother *is* the transform wrapper "native scroll" rules out. Oryzo AI and Lama Lama ship neither. Recommendation: **no smooth-scroll library**; buy the feel with `scrub: 0.6–1`.

**`horizontalLoop()` gotchas** (from the [helper source](https://gsap.com/docs/v3/HelperFunctions/helpers/seamlessLoop/)): copy-paste only, not importable from `gsap`; measures `offsetLeft`/`width` once at creation so a column-count change needs a rebuild; `defaults:{ease:"none"}` is mandatory; `snap:1` exists because browsers shift widths by a pixel in flex layouts — disabling it causes visible jitter; `onReverseComplete` does a `totalTime` hack, so read `tl.progress()` + `gsap.utils.wrap`, never `totalTime()`; needs **GSAP ≥ 3.14** or an inertia-jump workaround branch fires.

**`containerAnimation` hard limits** (official): the container tween **must** use `ease:"none"`; **pinning and snapping are not available** on containerAnimation-based triggers; do not animate the trigger element horizontally without offsetting start/end. Start/end strings are read horizontally (`"left center"`, `"right right"`).

**InertiaPlugin is free.** GSAP 3.13 (29 Apr 2025) made every bonus plugin free including commercial use — [gsap.com/blog/3-13](https://gsap.com/blog/3-13/), [Webflow announcement](https://webflow.com/updates/gsap-becomes-free). Stale Club warnings in old pens can be ignored.

**Cross-cutting rules** (from `C:\Users\lucid\.agents\skills\gsap-*\SKILL.md`, plus the [ScrollTrigger config docs](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)):

- Transforms and `autoAlpha` only — never `width/height/top/left`. `will-change:transform` only on nodes that animate. `clearProps` on any transform prop clears the **whole** transform.
- ScrollTrigger belongs on the **timeline or a top-level tween only** — never a child, never nested. `scrub` XOR `toggleActions` (scrub wins). Create top-to-bottom or set `refreshPriority`. `refresh()` after fonts/images/dynamic content (resize is automatic, debounced 200 ms); any `x:()=>…` needs `invalidateOnRefresh:true`.
- Not in the skill files: `anticipatePin:1` kills the one-frame flash on fast scroll; `fastScrollEnd` (2500 px/s) and `preventOverlaps` stop reveal pile-ups; `pinReparent` **breaks descendant CSS selectors**; `content-visibility:auto` **breaks pinning**; flex parents default to `pinSpacing:false`. `normalizeScroll()` fixes iOS jitter but is experimental, drops on pinch, hides native scrollbars, and cannot stop the iOS address bar (`ignoreMobileResize:true`).
- `gsap.matchMedia()` auto-reverts everything created inside a query when it stops matching — that is the mobile kill-switch. Never nest `gsap.context()` in it; use `mm.revert()`.
- SplitText: the animation must live **inside `onSplit()` and be returned**, or `autoSplit` orphans it. One mask type. Split after `document.fonts.ready`. No `text-wrap:balance`. `aria:"auto"`.
- Astro islands: `useGSAP({scope: ref})`; anything creating GSAP objects in an event handler **must** be `contextSafe()`-wrapped. Never run GSAP during SSR.
- Native scroll needs **no** `scrollerProxy`. For section snap use `snap:{snapTo:1/(n-1), duration:{min:.2,max:.6}, directional:true}`, not an Observer switcher. All plugins free since 3.13 — no `.npmrc` token; 3.15 (13 Apr 2026) adds adaptive directional easing.

**The five stack decisions**

1. **Do not use drei `ScrollControls`.** Its [source](https://github.com/pmndrs/drei/blob/master/src/web/ScrollControls.tsx) appends its own `overflow:auto` div to the canvas's parent — [docs](https://drei.docs.pmnd.rs/controls/scroll-controls): *"Scroll controls create an HTML scroll container in front of the canvas."* In Astro, markup outside the island then cannot scroll with the 3D. Instead: ScrollTrigger `onUpdate` writes **one number** into a module-scope store; `useFrame` owns all rAF work and damps toward it. Canvas island = `client:only="react"`, below-fold = `client:visible`. [@14islands/r3f-scroll-rig](https://github.com/14islands/r3f-scroll-rig) gives DOM→mesh tracking on native scroll.
2. **`MeshTransmissionMaterial` is a trap.** The [docs](http://drei.docs.pmnd.rs/shaders/mesh-transmission-material) admit *"it causes an additional render pass"*; with `backside` the scene renders 3× total, at a **fullscreen** default `resolution` — 1.32 Mpx re-rendered 1–2× per frame on a 390×844 phone at DPR 2. If unavoidable: `resolution={32}`, `backsideResolution={32}`, `backside={false}`, `samples={2}`. For the floor, use set piece B.
3. **drei [`<View>`](https://drei.docs.pmnd.rs/portals/view) for the 96-photo grid.** Views *"use `gl.scissor` to cut the viewport into segments"* tied to DOM divs: one context, one rAF, shared textures — versus a browser cap of ~8–16 live contexts. CSS owns the grid; WebGL draws inside each tile. `frames={1}` for static views. This is what Oryzo AI ships.
4. **iOS video.** `useVideoTexture` already defaults `muted`, `playsInline`, `crossOrigin`. But WebKit's [policies](https://webkit.org/blog/6784/new-video-policies-for-ios/): *"`<video autoplay>` elements will only begin playing when visible on-screen"* and *"will pause if they become non-visible."* An offscreen texture video freezes — keep the element 1×1px in-viewport and drive `play()`/`pause()` yourself. **One playing video at a time on iPhone, two as a ceiling**; everything else is a poster JPEG. Lama Lama ships 24 and keeps 2 playing.
5. **Degrade automatically.** `<PerformanceMonitor factor={1} flipflops={3} onChange={({factor})=>setDpr(0.75+1.25*factor)} onDecline={()=>setQuality('low')} onFallback={()=>{setDpr(1);setQuality('low')}} />` plus `<AdaptiveDpr pixelated />` ([docs](https://drei.docs.pmnd.rs/performances/performance-monitor)). `flipflops={3}` + `onFallback` pins an oscillating device low permanently. `frameloop="demand"` for static chapters.

## 5. Dramatic copy — the pattern, then fifteen lines

The pattern on every winner probed: **one huge statement, one quiet caption, one number.** Terminal Industries splits a single sentence across a sticky hold ("…turns the space between your gate and your dock" → "into one connected, automated system"). ERA Residence breaks a sentence across three scroll beats ("THE COAST YOU WANTED / yours / THIS YEAR"). Oryzo opens on a negation ("ISN'T JUST A COASTER."). Rules: lines under seven words, verbs in the imperative, numbers set at display scale, the caption never competes with the statement.

## 6. What the jury punishes

Awwwards weights **Design 40 / Usability 30 / Creativity 20 / Content 10**, scored by ≥18 jurors with the three outlying scores dropped ([evaluation system](https://www.awwwards.com/about-evaluation/)). Usability is the second-largest block, and it is the one immersive sites lose.

| Anti-pattern | Why it costs you | Source |
|---|---|---|
| Scroll-jacking that traps | *"The majority of our study participants were at least mildly disoriented by scrolljacking"*; task-focused users disengage, some read it as a bug; users lose the way back to the top, worst with horizontal | [NN/g, Scrolljacking 101](https://www.nngroup.com/articles/scrolljacking-101/) |
| Jacking on mobile | Smaller screens make each jack longer and more disorienting; NN/g's guidance is explicitly **desktop only** | same |
| Reading during a scrub | Pages combining an altered scroll rate with readable text tested worst — users balance reading against keeping momentum | same |
| Ignoring `prefers-reduced-motion` | WCAG **2.3.3 Animation from Interactions** (AAA): non-essential motion from interaction must be disableable; scroll hijacking *"regularly clashes with assistive technology and with the settings users chose themselves"* | [W3C 2.3.3](https://www.w3.org/WAI/WCAG21/Understanding/animation-from-interactions.html), [C39](https://www.w3.org/WAI/WCAG21/Techniques/css/C39), NN/g |
| Heavy above the fold | LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1 at p75; INP is the most-failed metric | [web.dev thresholds](https://web.dev/articles/defining-core-web-vitals-thresholds) |
| Unreadable text over film | Fixes it costs nothing: a scrim, or move type off the video entirely. McAlpine House wins a Dev SOTY nomination with three videos and zero canvas | [mcalpinehouse.com](https://mcalpinehouse.com) |
| Text living in WebGL | No `alt`, no selection, no indexing — unseen.co/world has **zero `<img>` in the DOM** and `body{overflow:hidden}` | [unseen.co/world](https://unseen.co/world/) |
| Stray triggers and tweens | Uncleaned ScrollTriggers keep running on dead nodes, hurting perf and correctness | `gsap-performance`, `gsap-scrolltrigger` SKILL.md |

**Non-negotiables:** the wheel always moves the page; `@media (prefers-reduced-motion: reduce)` kills scrubs, parallax and the sequence (poster frame instead); no scrub section above the fold; never two videos decoding at once; every photo keeps a real `<img alt>`.
