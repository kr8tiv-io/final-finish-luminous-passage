## Notes on scope

- This table covers only the items named in plan decision B2. Anything found in G1 or G3 during later steps that is not listed here should be added to this table (with source-path verification) before being ported, not silently merged.
- "Keep, reworked" entries are deliberate: several G1/G3 ideas are good in spirit but were built in a way that reintroduces a second state owner (A3's root-cause class of bug). The rework column above states explicitly how each is being kept without repeating that mistake.
- G3's 30-point list is a creative brainstorm, not a build plan Matt approved line-by-line — only the specific points cited above are harvested; the rest (baked lightmaps, HDRI environment maps, ambient sound, contextual lighting matching in the visualizer, etc.) are out of scope unless a future step cites them explicitly against this table.
